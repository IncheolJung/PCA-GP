

This manual is a user guide to use \texttt{Parallelized Gaussian Process Interpolative Decomposition} (\texttt{P-GP-ID}) enabling \textbf{efficient frequency sweep} for \texttt{VWT-IE-Solver-Unified-DG.x} solver. This code pre-requisites \texttt{Python} with installed packages \href{https://numpy.org/}{\texttt{numpy}}, \href{https://scipy.org/}{\texttt{scipy}}, and \href{https://scikit-learn.org/stable/}{\texttt{scikit-learn}}. Also, the current version is \textbf{alpha-version}, indicating upcomming updates may lead many parts of this manual to be deprecated.
